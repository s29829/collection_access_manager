Collection Access Manager

Which user groups can see which featured collections – in one table with the collection tree.

ResourceSpace stores access to featured collections as codes in the group permissions. Collection Access Manager shows them as a table: rows are the featured collection tree, columns are user groups. Tick a box instead of working out the codes.

Features

Access table with tree

Featured collection categories and collections with indentation. Ticking an entry also ticks its parent categories, so the access always works.

Correct codes

The plugin writes the same access codes that ResourceSpace itself computes, including "all collections" and hidden branches.

Manage folders

Create, rename and delete featured collection folders directly in the tree.

Filters

Search collections, show only rows where groups differ or rows with unsaved changes, open or close the whole tree.

Copy and history

Copy access from one group to another; every save keeps the previous state in the version history for restoring.

Inheritance aware

Groups that inherit permissions from a parent group are shown read-only, so the table never contradicts ResourceSpace.

Installation

In ResourceSpace

  1. Download the .zip above.
  2. In ResourceSpace open Plugin Manager > Upload a plugin and upload the file.
  3. Activate Collection Access Manager in the list of installed plugins, then open its Options.

Updating: upload the new .zip and choose Overwrite. Settings and data are kept in the filestore, outside the plugin folder.

On the server (command line)

# download and unpack – <RS_ROOT> is your ResourceSpace folder
cd /tmp
curl -fLO https://github.com/s29829/collection_access_manager/releases/download/v1.08/collection_access_manager-1.08.zip
# only when updating – the plugin data stays in the filestore
sudo rm -rf <RS_ROOT>/plugins/collection_access_manager
sudo unzip -q collection_access_manager-1.08.zip -d <RS_ROOT>/plugins/
sudo chown -R www-data:www-data <RS_ROOT>/plugins/collection_access_manager

www-data is the user that runs PHP (Apache on the RHEL family: apache). Then activate the plugin in System > Plugins. With git: git clone https://github.com/s29829/collection_access_manager <RS_ROOT>/plugins/collection_access_manager
